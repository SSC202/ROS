# 显卡驱动安装

> 前提：安装 Ubuntu 时没有安装显卡驱动。

## 1. (推荐) Nvidia+Cuda 安装

用这种方式可以把 Nvidia 和 Cuda 环境一起安装。[网址](https://developer.nvidia.com/cuda-12-8-0-download-archive?target_os=Linux&target_arch=x86_64&Distribution=Ubuntu&target_version=22.04&target_type=runfile_local)

推荐使用 `runfile` 安装。

 ```shell
 $ wget https://developer.download.nvidia.com/compute/cuda/12.8.0/local_installers/cuda_12.8.0_570.86.10_linux.run
 $ sudo sh cuda_12.8.0_570.86.10_linux.run
 ```

剩下操作和 Windows 一致。

使用以下指令检查环境：

```shell
$ nvidia-smi
```

> - 报错：
>
>   ```shell
>   -> The file '/tmp/.X0-lock' exists and appears to contain the process ID '1359' of a running X server.
>   -> You appear to be running an X server.  Installing the NVIDIA driver while X is running is not recommended, as doing so may prevent the installer from detecting some potential installation problems, and it may not be possible to start new graphics applications after a new driver is installed.  If you choose to continue installation, it is highly recommended that you reboot your computer after installation to use the newly installed driver. (Answer: Abort installation)
>   ERROR: Installation has failed.  Please see the file '/var/log/nvidia-installer.log' for details.  You may find suggestions on fixing installation problems in the README available on the Linux driver download page at www.nvidia.com.
>   ```
>
>   这是因为桌面图形程序没有关闭，导致无法安装显卡驱动。
>
>   1. 进入纯文本模式：按 `Ctrl + Alt + F3` 切换到纯文本终端。
>
>   2. 使用用户名和密码登录；
>
>   3. 停止图形界面服务：
>
>      - 方法1：
>
>        ```shell
>        $ sudo systemctl stop gdm3        # 对于 GNOME
>        $ sudo systemctl stop lightdm     # 对于 LightDM
>        $ sudo systemctl stop sddm        # 对于 KDE
>        ```
>
>      - 方法2：
>
>        ```shell
>        $ sudo systemctl isolate multi-user.target
>        ```
>
>   4. 然后运行安装程序即可，安装结束后重启。
