# ROS2 地图基本概念

## 1. 地图基本概念

机器人运动控制中，常用的地图有：

1. **栅格地图**：将空间划分为均匀的网格，每个网格存储一个值，表示该网格是否被占用（占用、空闲、未知）。常用于二维平面地图，机器人在栅格中规划运动轨迹。

   栅格地图中每一个格子存放一个概率表示被占据的概率。一般会设定两个阈值：占据阈值和空闲阈值。

2. **特征地图**：仅保留特征点的地图，常见于视觉SLAM。特征点可以是点特征、线特征或面特征。

3. **拓扑地图**：以节点和边的形式表示环境，节点表示位置，边表示路径。
   常用于大规模环境的导航和路径规划。

## 2. 栅格地图

栅格地图由一个`.yaml`格式的元数据文件，和`.pgm`图片格式的地图数据文件组成。

`.pgm` 文件可以直接看到地图。使用图片编辑软件可以直接编辑。

`.yaml` 文件是配置文件。

```yaml
image: fishbot_map.pgm
mode: trinary
resolution: 0.05
origin: [-3.37, -2.88, 0]
negate: 0
occupied_thresh: 0.65
free_thresh: 0.25
```

> - `image`：图像名称；
> - `mode`：图像模式，默认为`trinary`(三进制)，还有另外两个可选项`scale`(缩放的)和`raw`(原本的值)。
> - `resolution`：分辨率，一个栅格对应的物理尺寸，单位为m。0.05则表示一个栅格为0.05m。
> - `origin`：地图原点位置，单位是m。
> - `negate`：是否反转图像。
> - `cooupied_thresh`：占据阈值。
> - `free_thresh`：空闲阈值。

- 在 Rviz2 中显示地图

  ```shell
  $ ros2 run nav2_map_server map_server --ros-args --param yaml_filename:=fishbot_map.yaml # 指定地图描述文件
  $ rviz2
  $ ros2 lifecycle set /map_server configure # 配置节点
  $ ros2 lifecycle set /map_server activate  # 激活节点
  ```

  > `map_server` 节点采用的是 ROS2 的生命周期进行编写的，除了启动节点，我们还需要手动的配置和激活节点才能使用。
